# 🚀 How to Run FusionFlow AI

## Quick Start (3 Steps)

### Step 1: Install Dependencies
```bash
cd fusionflow-ai/frontend
npm install
```
⏱️ Takes 1-2 minutes

### Step 2: Start Development Server
```bash
npm run dev
```

### Step 3: Open in Browser
```
http://localhost:5173
```

---

## 🎯 That's It!

The application will automatically open in your default browser, or you can manually navigate to the URL above.

---

## 🎬 What You'll See

1. **Landing Page** - Beautiful hero with animated particles
2. Click **"Start Integration"**
3. **Upload Page** - Drag & drop 2 ZIP files (or just click through)
4. **Dashboard** - Watch AI analyze (auto-progresses)
5. **Analysis** - Interactive architecture graph
6. **Conflicts** - See detected issues
7. **Fixes** - View generated code
8. **Output** - Download integration package

**Total Demo Time:** 2-3 minutes

## 🐛 Troubleshooting

### Port Already in Use?
```bash
# Use a different port
npm run dev -- --port 3000
```

### Dependencies Not Installing?
```bash
# Clear and reinstall
rm -rf node_modules package-lock.json
npm install
```

### Build Errors?
```bash
# Check Node version (need 18+)
node --version

# If needed, update Node.js
```
